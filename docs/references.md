# Research ideas that informed Melior

These papers provide conceptual and algorithmic reference points. Their published results **do not imply** that Melior has reproduced those results.

1. Selinger et al., *Access Path Selection in a Relational Database Management System* (SIGMOD, 1979). https://research.ibm.com/publications/access-path-selection-in-a-relational-database-management-system
2. Ong et al., *RouteLLM: Learning to Route LLMs with Preference Data* (2024). https://arxiv.org/abs/2406.18665
3. Kim et al., *An LLM Compiler for Parallel Function Calling* (ICML 2024). https://arxiv.org/abs/2312.04511
4. Zhang et al., *AFlow: Automating Agentic Workflow Generation* (ICLR 2025). https://proceedings.iclr.cc/paper_files/paper/2025/hash/5492ecbce4439401798dcd2c90be94cd-Abstract-Conference.html
5. *Optimizing Agentic Workflows using Meta-tools* (2026). https://www.microsoft.com/en-us/research/publication/optimizing-agentic-workflows-using-meta-tools/
6. *SCOPE: Cost-Efficient Model Selection for Compound AI Systems under Quality Constraints* (2026). https://arxiv.org/abs/2606.00774

Questions for future research include: how to estimate step usefulness from task-level feedback, how to optimize under side effects, when verification overhead offsets savings, and whether cost-aware planning generalizes between agent frameworks.
