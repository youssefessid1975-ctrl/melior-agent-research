# Limitations and open questions

- The broad learned execution optimizer is a **research direction**, not a demonstrated capability.
- Real-agent cost reduction under unchanged success requirements has **not** been established.
- A synthetic workload engineered for repeated reads does not estimate natural duplicate frequency.
- The historic full implementation remains **private**; the public demo is only an illustrative companion.
- The reported 338-test checkpoint is an internal verification result, **not** an independent audit.
- The mini-SWE-agent integration was tested with controlled **offline fixtures**; genuine external model and tool calls were not exercised in that checkpoint.
- Official end-to-end SWE-bench cloud grading was not verified.
- Modal's prepared isolated runtime still required a live compatibility test and cloud billing reconciliation.
- API costs, simulated replay costs, and cloud charges are different quantities; do not combine them casually.
- The proportion of original Python source generated by Codex and the applicant's exact manually authored functions should be supported by repository provenance, not inferred from a leadership title.
